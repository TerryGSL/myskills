# 进度汇报

## 派发后立即
告诉用户启动了什么：

```
| # | Agent | 任务 | 状态 |
|---|-------|------|------|
| 1 | Explore | 搜索 auth 相关配置文件 | 🔄 进行中 |
| 2 | Research | 查询 Cloudflare 免费额度 | 🔄 进行中 |
| 3 | 主 Agent | 修复登录 bug | 🔄 进行中 |
```

## 单个 Agent 完成时
简短更新：「Agent 1 完成：找到 3 个配置文件。等待 Agent 2。」

## 全部完成时
合成报告 + 可执行的下一步建议。

---

## 进度汇报模板

派发 Agent 后，立即告知用户：

```
| Agent | 负责文件 | 任务 | 状态 |
|-------|---------|------|------|
| {descriptive name} | {files} | {what it does} | 🔄 运行中 |
```

每个 Agent 完成时，内联更新：
- "✅ {agent name} 完成：{一句话总结}"

全部完成时：
- 完整验证结果（tsc + 测试）
- 提交信息预览
- 发现的任何问题
