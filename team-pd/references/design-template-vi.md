输出 VI 设计规范（交互流程、页面布局、设计 Token），写入 `docs/DESIGN.md`：

```markdown

> 本文件描述交互流程、页面布局和数据流向。
> 所有样式必须使用项目根目录 DESIGN.md 中定义的 token。
```

```
## 4. 错误处理模式

| 错误类型 | 展示方式 | 用户操作 |
|----------|----------|----------|
| 网络超时 | Toast + 自动重试3次 | 手动重试按钮 |
| 服务端 5xx | 全屏错误页 | 刷新页面 |
| 校验失败 | 表单字段下方红色提示 | 修正后重提交 |
| 权限不足 | 跳转 403 页面 or 操作按钮隐藏 | — |
| 业务异常 | Toast 提示具体原因 | 按提示操作 |

| 次操作按钮 | Button | md, default | `--color-border` |
| 输入框 | Input | md | `--radius-md` |
| 表格 | Table | — | comfortable 模式 |
```
